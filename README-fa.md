# diyanet-mcp 🇹🇷

mcp-name: io.github.mohammad-abbasi-sh/diyanet-mcp

سرور MCP غیررسمی و **فقط‌خواندنی** برای **اوقات نماز دیانت** (namazvakitleri.diyanet.gov.tr) — **جدول رسمی منتشرشده**ٔ ریاست امور دینی ترکیه (Diyanet İşleri Başkanlığı): ۶ وقت نماز امروز برای هر یک از **۸۱ استان و شهرستان‌ها**، جدول سالانه با تاریخ میلادی + هجری، و زاویه/زمان قبله به‌همراه طلوع و غروب نجومی خورشید برای هر مکان.

> بخشی از «کارخانهٔ MCP ترکیه». وابسته به دیانت نیست. داده‌ها از خود سایت اوقات نماز دیانت می‌آیند (صفحه‌های رندرشده در سرور + JSON فهرست مناطق) — بدون ورود، بدون کلید API، فقط‌خواندنی. این سرور **جدول رسمی** را می‌دهد، نه یک تقریب محاسباتی: سرورهای عمومی اوقات نماز وقت‌ها را محاسبه می‌کنند (روش ۱۳ Aladhan با نام «دیانت» می‌تواند یکی‌دو دقیقه با وقت‌های رسمی فرق داشته باشد) و تنها ابزار دیگرِ مبتنی بر دیانت فقط ۲۰ شهر را پوشش می‌دهد.

## برای ایجنت‌های هوش مصنوعی

- **مکان‌ها**: یک استان (`"Ankara"`)، یک استان/شهرستان (`"İstanbul/Beylikdüzü"`، `"Ankara/Çankaya"`) یا کد عددی شهرستان (`"9541"` برای استانبول). فقط نام استان، شهرستان مرکزی را برمی‌گرداند.
- **نام‌ها نسبت به حروف ترکی حساس نیستند**: `"Cankaya"`، `"ÇANKAYA"` را پیدا می‌کند و `"istanbul"`، `"İSTANBUL"` را. نام‌های ترکی و انگلیسی هر دو کار می‌کنند.
- **شهرستان‌های وابسته به مرکز**: دیانت برای همهٔ شهرستان‌ها جدول جداگانه منتشر نمی‌کند — شهرستان‌های داخل‌شهری یک استان (مثلاً چانکایای آنکارا) به شهرستان مرکزی وابسته‌اند. ابزارها آن‌ها را به جدول مرکزی می‌رسانند و در پاسخ می‌گویند (`requested_district` + `note`)؛ شهرستانی که واقعاً ارائه شده همیشه گزارش می‌شود.
- **زبان‌ها**: `lang` برابر `"tr"` (پیش‌فرض)، `"en"`، `"ar"`، `"de"` یا `"fr"` — نسخه‌های زبانی خود سایت. وقت‌ها در همهٔ زبان‌ها یکسان‌اند.
- **جدول سالانه**: `diyanet_yearly_times` کل سال تقویمی را می‌دهد (۳۶۵ سطر) — اول ماه آینده، بعد از ۱ ژانویه تا پایان سال. هر سطر تاریخ میلادی + هجری دارد.
- هر پاسخ `fetched_at` (UTC) و `source: namazvakitleri.diyanet.gov.tr` دارد. وقت‌ها به وقت محلی اروپا/استانبول‌اند.

## نصب

```bash
uvx diyanet-mcp
```

یا به پیکربندی کلاینت MCP خود اضافه کنید (مثلاً Claude Desktop):

```json
{
  "mcpServers": {
    "diyanet": {
      "command": "uvx",
      "args": ["diyanet-mcp"]
    }
  }
}
```

## ابزارها

| ابزار | چه می‌کند |
| --- | --- |
| `diyanet_prayer_times` | ۶ وقت امروز (imsak, gunes, ogle, ikindi, aksam, yatsi) + تاریخ میلادی/هجری + زاویه/زمان قبله + طلوع و غروب نجومی برای یک مکان |
| `diyanet_yearly_times` | جدول سالانه: هر روز یک سطر (میلادی + هجری + ۶ وقت)، ۳۶۵ سطر (محدوده ۱ تا ۳۶۵) |
| `diyanet_list_provinces` | ۸۱ استان با کدهای دیانت و نام‌های ترکی + انگلیسی (فیلتر زیررشته‌ای اختیاری) |
| `diyanet_list_districts` | شهرستان‌های یک استان (با نام یا کد) با کدها، نام‌ها و آدرس صفحه‌ها |
| `diyanet_qibla` | زاویهٔ قبله (درجه از شمال)، زمان قبله، طلوع و غروب نجومی برای یک مکان |
| `diyanet_health` | آیا سایت اوقات نماز دیانت همین حالا در دسترس است؟ |

## نمونه

استانبول، ۱۷ نوامبر ۲۰۲۶ (۸ جمادی‌الآخر ۱۴۴۸):

```json
{ "place": "İstanbul", "ilce_id": 9541,
  "times": { "imsak": "06:18", "gunes": "07:47", "ogle": "12:54",
             "ikindi": "15:28", "aksam": "17:51", "yatsi": "19:15" },
  "qibla_angle_deg": 147, "qibla_time": "11:01" }
```

## نکته‌ها

- وقت‌ها جدول رسمی دیانت‌اند — پیش از عمل به آن‌ها در namazvakitleri.diyanet.gov.tr بررسی کنید.
- دیانت برای آنکارا فقط ۱۷ شهرستان فهرست می‌کند (شهرستان‌های داخل‌شهری جدول مرکزی را مشترک دارند)؛ ابزارها شهرستانی را که واقعاً ارائه شده گزارش می‌کنند.
- ترتیب سطرهای جدول سالانه همان ترتیب صفحه است (اول ماه آینده، بعد از ۱ ژانویه) — هر سطر تاریخ خودش را دارد، اگر ترتیب زمانی می‌خواهید بر اساس تاریخ مرتب کنید.
- انتقال با جعل TLS کروم و پشتیبان درخواست ساده انجام می‌شود؛ درخواست‌ها با فاصلهٔ حدود ۰٫۵ ثانیه فرستاده می‌شوند.
